# One extension beyond the letter, named rather than left silent: Karlin states the
# variation-diminishing conclusion for bounded Borel f, while IsVariationDiminishingOrd follows
# the node ("every integrable or bounded g") and admits integrable f too. It touches only
# variationDiminishing_of_polyaExponent; in the other direction the wider quantifier is a
# hypothesis, where wider is narrower. Since 2026-09-11 it is the ONLY extension that leg
# carries on its own.

# A SECOND EXTENSION WAS DECLARED AND HAS BEEN DISCHARGED (fidelity review R14; the author's
# decision (b), 2026-09-11). signChangesAE is an infimum over EVERY a.e. representative,
# non-measurable ones included, where Karlin counts S^-(f) on a bounded Borel f. The necessity
# leg was always safe -- hac makes mu * g continuous, the two counts agree there, and on the
# right the essential count is at most the ordinary one. The sufficiency leg needed one thing
# more, and that thing is now proved, not believed: given a measurable g and any h equal to it
# almost everywhere, delete g on a measurable null superset N of the set where the two differ.
# The result 1_{N^c} g is measurable, is again a representative of g, has |h'| <= |g| pointwise
# (so it inherits integrability or boundedness), and equals h wherever it is nonzero -- so every
# alternation of it is an alternation of h at the same points, and S^-(h') <= S^-(h). Hence the
# infimum is attained along measurable representatives, and Karlin's ordinary-count conclusion
# implies the essential-count one. The axiom now concludes IsVariationDiminishingOrd, Karlin's
# letter; SpatialLine.isVariationDiminishing_of_polyaExponent carries it the rest of the way.
